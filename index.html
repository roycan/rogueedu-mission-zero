Mission Zero:
Get the project onto your computer

Before we launch the game, let's learn four small actions: open Git Bash, make a folder, download the project with Git, and open that folder in VS Code.

⏱ About 10–15 minutes · No coding yet
One command at a timeType a line, press Enter, then look at the result.
Prompts are not commandsDo not type the text or dollar sign shown before a command.
Errors are cluesStop and ask for help. Do not delete folders to fix things.

1
Find the right window

Open Git Bash from the Start menu

We will open Git Bash directly from Windows first. That way, we do not need to know VS Code's terminal settings yet.

  1. Click the Windows Start button.
  2. Type Git Bash.
  3. Click the app named Git Bash.
What is this?
Think of Git Bash as a text-based remote control for your computer. We type short instructions instead of clicking through folders.
MINGW64 — Git Bash
student@LAPTOP MINGW64 ~
$ ▍ waiting for your command

Your window may show a different computer or student name. That's normal. Look for the Git Bash window and a place to type after the $.

Important: The $ is the prompt, not part of your command. Type only what appears in the command boxes below.
2
Make a home for the project

Create a folder, then move into it

We will put the project in a folder called RogueEdu inside your own Windows user folder. This avoids creating a folder directly under C:\.

A · Create the folder
mkdir -p ~/RogueEdu

Say it in ordinary language: “Make a folder named RogueEdu.” This command is safe to run again if the folder already exists.

B · Move into that folder
cd ~/RogueEdu

Say it in ordinary language: “Change directory; go into RogueEdu.”

C · Check where you are
pwd
What should you see?
A location that ends with /RogueEdu. Your username and earlier path may be different.
Git Bash · example output
$ pwd
/c/Users/Student/RogueEdu

This is an example. Your name and path will probably differ.

Remember these two words: mkdir makes a directory (folder). cd changes the directory you are working in.
3
Get the class project

Clone the repository from GitHub

A repository (often shortened to “repo”) is a project folder tracked by Git. Clone means download your own working copy of that repository onto this computer.

Check that the last command's location ended in /RogueEdu. Then type this one line:

git clone https://github.com/roycan/pygame-engine.git

What happens next?

  1. Git contacts GitHub.
  2. It creates a new folder named pygame-engine.
  3. It fills that folder with the project files.
  4. Wait until the download finishes and the prompt comes back.
Git Bash · example output
Cloning into 'pygame-engine'...
Receiving objects: 100% ...
Resolving deltas: 100% ...
$ ▍ ready for the next command

The percentages and wording can vary. Wait for the prompt to return.

You do not need to sign in to GitHub just to clone this public class repository. If a sign-in window or error appears, stop and show the teacher rather than entering a password.
4
Open the exact project folder

Move into the repo, then launch VS Code

First go inside the newly created project folder. Then ask VS Code to open the folder you are standing in.

A · Enter the project folder
cd pygame-engine
B · Open this folder in VS Code
code .
What does the dot mean?
The dot . means “the folder I am in right now.” Since we moved into pygame-engine, this command opens that project—not the larger RogueEdu folder and not just one file.

What should VS Code look like?

Look at the Explorer panel on the left. The top folder should be pygame-engine. Under it you should find items like:

📁 pygame-engine ├── README.md ├── 📁 rogue_edu ├── requirements.txt └── 📁 tests

Click README.md in the left panel to read about the project.

Illustration, not a screenshot. Your VS Code theme may look different.

If code . says “command not found”: don't repeat it or change random settings. Open VS Code from the Start menu, choose File → Open Folder, and select pygame-engine inside your RogueEdu folder under your Windows user folder. Ask the teacher if you cannot find it.

✅ Mission Zero complete!

You do not need to understand every Git command yet. For today, know what each action did.

🛟 If something goes wrong

Pause. Keep the error message visible and call the teacher. Don't delete folders, reinstall tools, or type extra commands to guess your way out.

“git: command not found”Git Bash may not be installed correctly. Tell the teacher.
“destination path already exists”The repo folder may already be there from an earlier attempt. Do not delete it; call the teacher.
Download appears stuckWait briefly and check for a message. Keep the window open and ask for help.
VS Code opened the wrong placeClose that window and ask the teacher to help open the pygame-engine folder.
